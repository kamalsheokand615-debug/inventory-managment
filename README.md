## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/kamalsheokand615-debug/inventory-management.git
```

### 2. Open the project folder

```bash
cd inventory-management
```

### 3. Install dependencies

If the project uses Bun:

```bash
bun install
```

### 4. Environment Variables

Create a `.env` file using `.env.example` as a reference.

```bash
cp .env.example .env
```

Then add the required environment variables to the `.env` file.

> Never upload your real `.env` file or secret keys to GitHub.

## ▶️ Running the Project

Run the development server using the command configured in your project.

For Bun projects, it may be:

```bash
bun run dev
```

## 🔐 Security

* Keep secret keys and passwords inside `.env`.
* Do not commit sensitive credentials to GitHub.
* Use `.env.example` to show required environment variables without exposing their values.
